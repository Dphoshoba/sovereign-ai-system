## Major Decisions

1. Composition over modification — all capability added above certified foundations
2. Governance before automation — policy, approval, audit precedent
3. Evidence before recommendation — every output traceable to data
4. Executive authority preserved — platform advises, never selects or executes
5. Production data isolation — explicit isTest boundary, CI-enforced
