## Description

Maintains operational documentation for discoverability and accuracy. Integrates with Knowledge Office for documentation storage. Governed by O-005: documentation refreshed within 90 days or flagged as stale.

## Capabilities

- operations.documentation — freshness scores, outdated-content flags, coverage gap analysis
