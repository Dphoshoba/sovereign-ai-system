## Description

Monitors project status across the organization with dependency-aware progress tracking. Uses Federated Observability (8D) for project telemetry and Cross-Platform Coordination (8B) for cross-project queries. Governed by O-002: at-risk projects >2 weeks behind auto-escalate.

## Capabilities

- operations.project-tracking — project health dashboard, milestone forecasts, blocker escalation, resource conflict detection
